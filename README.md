# 🌸 She Track – Women's Health & Period Tracker App

**She Track** is a smart and intuitive **Flutter-based Women's Health Tracker App** designed to help users monitor their menstrual cycles, track symptoms, and gain insights into their health.

Powered by **Firebase**, the app provides a seamless and secure experience for tracking and managing personal health data.

---

## 🚀 Features

* 📅 Period Tracking System
* 🩸 Log Cycle Dates & Symptoms
* 📆 Calendar View for Cycle Visualization
* 📊 Health Insights (extendable)
* 🔔 Smart Alerts for Irregular Cycles *(planned)*
* ☁️ Firebase Integration
* 🎨 Clean & User-Friendly UI

---

## 🛠️ Tech Stack

* Flutter (UI Framework)

## 🚀 How to Run

1. Install Flutter SDK

2. Clone the repository:

   ```bash
   git clone https://github.com/your-username/she-track.git
   ```

3. Navigate to project:

   ```bash
   cd she-track
   ```

4. Install dependencies:

   ```bash
   flutter pub get
   ```

5. Run the app:

   ```bash
   flutter run
   ```

---

## 🔥 Firebase Setup

1. Go to Firebase Console
2. Create a new project
3. Add Android/iOS app
4. Download configuration files
5. Place them in your project
6. Ensure `firebase_options.dart` is configured
